# ShaderBridge — Official Documentation & Support

**ShaderBridge** is a 100% offline Shadertoy-compatible GLSL to Unreal Engine Material converter plugin for Unreal Engine (Win64 Editor), powered by unmodified open-source Khronos SPIR-V / SPIRV-Cross / glslang compiler tools digitally signed by LunarG, Inc.

> **Note**: This public repository hosts user documentation, release notes, and the official issue tracker for **ShaderBridge** (distributed on Epic Fab). It contains no plugin source code.
